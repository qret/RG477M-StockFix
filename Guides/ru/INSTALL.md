# Руководство по установке и работе модуля (RU)

## 1. Требования
- **Устройство:** Anbernic RG477M (MT6897 / Dimensity 8300) на стоковой прошивке **V1.32**.
- **Root-доступ:** установленный Magisk (если root ещё не установлен, воспользуйтесь **[RG477M-Toolkit](https://github.com/qret/RG477M-Toolkit)** — безопасный бэкап стока, Magisk v31.1 без сброса данных и откат в 1 клик).

## 2. Установка и обновление

### Способ А: Прямо на консоли (рекомендуется)
1. Скачайте **`RG477M-StockFix.zip`** со страницы **[Releases](https://github.com/qret/RG477M-StockFix/releases/latest)**.
2. Откройте **Magisk → Модули → Установить из хранилища**.
3. Выберите `RG477M-StockFix.zip` и перезагрузите консоль.
4. Все последующие обновления Magisk подтянет сам по `updateJson` — кнопка **«Обновить»** появится прямо в списке модулей.

### Способ Б: Через ADB с компьютера
```sh
adb push RG477M-StockFix.zip /data/local/tmp/
adb shell su -c "magisk --install-module /data/local/tmp/RG477M-StockFix.zip"
adb shell rm -f /data/local/tmp/RG477M-StockFix.zip
adb reboot
```
*(Если на свежем headless-руте отсутствует `/data/adb/magisk/util_functions.sh`, откройте приложение Magisk один раз или используйте Шаг 3 в `RG477M-Toolkit`.)*

## 3. Как работают режимы в шторке

### Профили производительности (`persist.sys.cpu.mode`)
| Режим в шторке | Политика CPU | Политика GPU / GED | Экран ВЫКЛ / простой |
| :--- | :--- | :--- | :--- |
| **`bal` (`1`)** | `schedutil` (`1000 мкс`), `cpuidle=teo`, `top-app uclamp.min=45` | Разблокированы `1400 МГц`, GED `margin=130`, `timer=50`, `step=15`, `floor=265 МГц` | Падает до `265 МГц` GPU / `400 МГц` CPU |
| **`game` (`2`)** | `schedutil` (`1000 мкс`), `uclamp.min=55`, floor mid-кластера `1400 МГц` | Разблокированы `1400 МГц`, GED `margin=130`, `timer=40`, `step=18`, 3D floor `780 МГц` (`OPP 38`) | Падает до `265 МГц` GPU / `400 МГц` CPU |
| **`turbo` (`3`)** | Штатные частоты + `cpuidle=teo`, `uclamp.min=60` | Штатные частоты + `margin=130` | Штатный сброс |
| **`saver` (`0`)** | Экономный `schedutil` (`4000 мкс`), `uclamp=0` | Экономный `margin=530`, `floor=265 МГц` | Минимальное потребление |

### Плавные кривые вентилятора (`fan_mode`)
- **`bal` (`fan_mode=1`):** `<48°C → 0` · `48–56°C → 65` · `56–64°C → 85` · `64–72°C → 110` · `72–80°C → 145` · `80–85°C → 200` · `>=85°C → 255`.
- **`turbo` (`fan_mode=2`):** `<42°C → 80` · `42–52°C → 115` · `52–60°C → 150` · `60–68°C → 185` · `68–76°C → 220` · `>=76°C → 255`.
- **Выключенный экран (`Screen OFF`):** кулер мгновенно сбрасывается в `0 PWM` независимо от остаточной температуры SoC, права `pwm_fan_set` возвращаются в `666`, а тяжёлый опрос датчиков и `settings get` замораживаются для полноценного глубокого сна (`Suspend-to-RAM`).
- **`silent` и `fixed`:** полностью остаются под управлением штатной шторки (`chmod 666`).

### Анти-щелчок динамиков (`GPIO 5` / `is_fm_enable`)
- Экран ВКЛ и 3.5 мм джек отключён → `1.0` (аналоговый усилитель динамиков остаётся готовым без щелчков каждые 3 с).
- Вставлены наушники 3.5 мм → мгновенный переход на `0.1`.
- Экран ВЫКЛ → переход на `0.1`, как только `runtime_status` аудиоподсистемы покидает `active`.

## 4. Проверка работы и удаление
- Проверить активный процесс демона по ADB:
  ```sh
  adb shell su -c "ps -ef | grep rg477m_perf_daemon"
  ```
- **Удаление:** удалите модуль в **Magisk → Модули** и перезагрузите консоль, либо выполните:
  ```sh
  adb shell su -c "touch /data/adb/modules/rg477m_perf_tuning/remove"
  adb reboot
  ```
- **Защита от бутлупа:** `post-fs-data.sh` считает незавершённые загрузки и после 2 сбоев подряд автоматически создаёт флаг `disable`.
